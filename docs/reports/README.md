## 实验七说明

实验七报告题目为“使用 OpenCV 来进行平面视觉检测仿真”。实验在 Ubuntu 20.04、ROS Noetic、Gazebo 11 和 OpenCV 环境下完成，主要内容包括：

- 通过 ROS 图像话题获取机器人视觉图像。
- 使用 `CvBridge` 将 ROS `Image` 消息转换为 OpenCV 图像。
- 根据学号规则选择绿色球，使用 HSV 阈值分割和形态学处理提取目标。
- 根据目标质心位置输出 `/cmd_vel`，完成视觉跟随闭环控制。
- 使用 Haar 级联分类器完成人脸检测，并通过窗口和终端日志验证结果。

## 实验八说明

实验八报告题目为“机器人三维视觉仿真”。实验在 Ubuntu 20.04.5、ROS Noetic、Gazebo 11、RViz、`wpr_simulation` 和 `wpb_home` 环境下完成，主要内容包括：

- 启动桌面抓取仿真场景，观察机器人、桌面和待抓取物体。
- 通过 `/wpb_home/behaviors` 激活桌面物体检测。
- 读取 `/wpb_home/objects_3d` 输出的物体名称、三维坐标和置信度。
- 通过 `/wpb_home/grab_action` 或抓取行为服务器驱动机械臂执行抓取。
- 保存节点、话题、源码位置、Gazebo 过程和抓取结果等截图证据。

实验七、实验八的代码主要依赖 Ubuntu 虚拟机中的课程仿真包和临时脚本，仓库中保留的是最终报告和可复现的命令、话题、源码说明。
