# 从 0 启动山地城市仿真

本文档用于从零启动 `mountain_car_sim` 大作业：山地 + 城市街景 + 地面小车沿道路行驶 + 空中飞机巡航。

适用环境：

- Ubuntu 20.04
- ROS Noetic
- Gazebo 11
- 工作空间：`~/catkin_ws`
- 项目包：`~/catkin_ws/src/mountain_car_sim`

## 1. 打开虚拟机

在 Mac 上打开 VMware Fusion，进入 Ubuntu 桌面。

如果 Gazebo 或终端之前已经打开但很卡，可以先关闭旧进程：

```bash
pkill -f roslaunch
pkill -f gzserver
pkill -f gzclient
pkill -f road_follow_car.py
pkill -f uav_patrol_demo.py
```

## 2. 进入工作空间

打开 Ubuntu 终端，执行：

```bash
cd ~/catkin_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
```

如果提示 `devel/setup.bash` 不存在，说明还没有编译，先看下一步。

## 3. 编译项目

```bash
cd ~/catkin_ws
source /opt/ros/noetic/setup.bash
catkin_make
source devel/setup.bash
```

编译成功时，一般会看到类似：

```text
Built target mountain_car_sim
```

或者没有红色 error，也可以继续启动。

## 4. 一键启动最终演示

```bash
cd ~/catkin_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
roslaunch mountain_car_sim mountain_city_air_demo.launch
```

启动后 Gazebo 中应该能看到：

- 城市道路和建筑；
- 地面小车沿道路中心线行驶；
- 空中飞机在城市和山地区域上方巡航；
- 场景中包含山地、城市、道路过渡区、路灯、树、广告牌等模型。

## 5. 当前默认启动了什么

最终 launch 文件是：

```text
~/catkin_ws/src/mountain_car_sim/launch/mountain_city_air_demo.launch
```

它会自动启动三部分：

```text
1. Gazebo world：mountain_city_air_demo.world
2. 小车生成：spawn_mountain_car.launch
3. 小车道路巡航：road_follow_car.py
4. 飞机巡航：uav_patrol_demo.py
```

小车道路巡航脚本是：

```text
~/catkin_ws/src/mountain_car_sim/scripts/road_follow_car.py
```

它使用 `/gazebo/set_model_state` 控制小车位置，同时发布 `/cmd_vel`，所以即使 Gazebo 小车运动插件不稳定，小车也能稳定沿道路行驶。

## 6. 单独重启小车道路巡航

如果 Gazebo 已经开着，但小车不动，只重启小车脚本即可：

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash

pkill -f road_follow_car.py
rosrun mountain_car_sim road_follow_car.py _speed:=0.9 _z:=0.45
```

如果不想占用当前终端，可以后台运行：

```bash
cd ~/catkin_ws
nohup bash -lc "source /opt/ros/noetic/setup.bash; source devel/setup.bash; rosrun mountain_car_sim road_follow_car.py _speed:=0.9 _z:=0.45" > /tmp/road_follow_car.log 2>&1 &
```

确认小车节点是否还在：

```bash
ps -ef | grep road_follow_car
```

## 7. 单独重启飞机巡航

如果飞机不动，但 Gazebo 已经开着：

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash

pkill -f uav_patrol_demo.py
rosrun mountain_car_sim uav_patrol_demo.py _model_name:=patrol_airplane _altitude:=3.8 _speed:=2.2
```

## 8. 查看小车是否真的在动

可以用 Gazebo 服务读取小车位置，隔几秒看坐标是否变化：

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash

rosservice call /gazebo/get_model_state "model_name: mountain_car"
```

也可以看控制话题：

```bash
rostopic echo /cmd_vel
```

如果能看到 `linear.x` 有数值，说明控制节点正在发布速度。

## 9. 常见问题

### 9.1 Gazebo 打不开或一直黑屏

先关掉旧进程再重开：

```bash
pkill -f gzserver
pkill -f gzclient
pkill -f roslaunch
roslaunch mountain_car_sim mountain_city_air_demo.launch
```

### 9.2 城市有了，山地看不到

多数情况不是山地没加载，而是 Gazebo 视角正对城市。

可以在 Gazebo 中按住鼠标滚轮拖动、滚轮缩放，或者从左侧 `Models` 展开查看是否有：

```text
mountain_terrain
mountain_showcase_details
mountain_city_transition
```

如果模型资源路径异常，重新设置模型路径后再启动：

```bash
export GAZEBO_MODEL_PATH=~/catkin_ws/src/mountain_car_sim/models:$GAZEBO_MODEL_PATH
roslaunch mountain_car_sim mountain_city_air_demo.launch
```

### 9.3 小车生成了但不动

直接重启道路巡航脚本：

```bash
pkill -f road_follow_car.py
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
rosrun mountain_car_sim road_follow_car.py _speed:=0.9 _z:=0.45
```

### 9.4 飞机能飞，小车不动

这是因为飞机和小车都可以用 `/gazebo/set_model_state` 演示级控制。现在小车已经改成 `road_follow_car.py`，不依赖 Gazebo 车轮插件。

重点确认：

```bash
rosnode list | grep road_follow_car
ps -ef | grep road_follow_car
```

### 9.5 修改代码后没有生效

重新编译并 source：

```bash
cd ~/catkin_ws
source /opt/ros/noetic/setup.bash
catkin_make
source devel/setup.bash
```

然后重启 launch：

```bash
pkill -f roslaunch
pkill -f gzserver
pkill -f gzclient
roslaunch mountain_car_sim mountain_city_air_demo.launch
```

## 10. 答辩时推荐演示顺序

1. 打开终端，进入 `~/catkin_ws`。
2. 执行 `source /opt/ros/noetic/setup.bash` 和 `source devel/setup.bash`。
3. 执行 `roslaunch mountain_car_sim mountain_city_air_demo.launch`。
4. Gazebo 打开后，先展示城市道路、小车沿道路行驶。
5. 调整视角展示空中飞机巡航。
6. 说明小车脚本 `road_follow_car.py` 使用道路航点控制，飞机脚本 `uav_patrol_demo.py` 使用椭圆巡航控制。
7. 打开终端执行 `rostopic echo /cmd_vel`，展示小车控制话题。
8. 打开终端执行 `rosservice call /gazebo/get_model_state "model_name: mountain_car"`，说明可以读取小车在 Gazebo 中的位置。

## 11. 一句话介绍

这个项目用 ROS Noetic 和 Gazebo 11 搭建了一个山地到城市的综合仿真场景，小车通过道路航点沿城市道路行驶，飞机通过 Gazebo 状态服务在空中巡航，用于展示地面机器人和空中机器人在同一仿真环境中的协同演示。
